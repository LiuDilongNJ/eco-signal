# ecoSignal 用户指南

[English](user-guide.md) · [文档首页](../README_ZH.md)

**适用对象：** 研究人员、野外工作人员、上传人员、标注人员和审核人员。  
**开始前：** 请先登录，并取得目标项目和集合的访问权限。可见功能取决于你的权限范围。

## 在项目中工作

打开项目后选择集合，即可处理其中的音频、照片、站点、标注、审核及相关记录。使用可用的列表、地图和详情视图筛选并查看记录。未显示的项目、集合或操作通常不在当前访问范围内。

采集、上传、标注、审核和分析都应在具体集合范围内进行。项目和集合管理者会看到额外管理入口；详见[管理员指南](admin-guide.zh.md)。

## 上传和处理媒体

在上传抽屉中选择一个或多个音频或照片文件，等待分片上传完成后保存该批次。

- 上传分片只创建暂存记录，不会为每个文件创建 Queue 记录。
- 保存后会为已接受的批次创建一条 `upload` 队列记录。`total` 是提交文件数，`completed` 只统计成功创建的媒体数。
- 后台任务会依次合并文件、校验内容、检测重复项、创建媒体记录并生成预览。
- 重复文件会以警告结束；任一文件失败会使批次以错误结束。请在 Queue 中查看每个批次的结果。

无需一直打开上传抽屉等待完成：已保存的批次不会因关闭抽屉而取消。

## 标注、审核和分析

打开媒体记录可查看预览和元数据。权限允许时，可创建或编辑标注，并使用审核记录验证工作。图片查看器可显示或隐藏标注覆盖层。

分析操作会创建后台任务。请在 Queue 中跟踪进度，并在完成后打开媒体或结果记录查看输出。若没有可用操作，请向管理者申请对应的集合权限。

## 导入表格数据

支持导入的 Data 列表在 **Add** 菜单中提供导入入口；Audio 和 Photo 保持现有 **Metadata** 菜单标签。准备文件前，可从同一菜单选择 **Import Instructions** 或 **Metadata Instructions** 查看字段并下载对应 CSV 模板。

文件可使用 `.csv`、`.txt` 或 `.json`。分隔文本支持逗号、Tab、分号和竖线；`.txt` 也可使用 JSON 对象数组。CSV 和分隔文本必须包含表头。

首次提交只校验全部行，不写入数据。请在浏览器中查看报告、修正错误后，再确认提交同一文件，以一个原子事务导入。重复行会跳过，其他任一失败行都会阻止批次提交。导入集合范围资源前必须选择目标项目和集合。

## 使用离线集合包

### 导出

打开 **Data > Collections**，选择一个集合并点击 **Export Bundle**。应用会在后台生成完整媒体包，并在完成后提供下载；文件保留 24 小时。

### 导入

选择目标项目，打开 **Data > Collections**，点击 **Import Bundle** 并选择一个 ZIP 文件。关闭抽屉后，进度、创建和跳过数量、冲突及警告仍可在 Queue 中查看。

目标 `project_id` 必须已存在，导入者必须在该项目上拥有 `project:write`。离线导入批次只接受 `.zip` 文件。服务会先验证包签名和 SHA-256 校验和。媒体 UUID 是身份键：UUID 和二进制内容一致时会复用并关联到目标集合，UUID 相同但内容不同会中止导入。不同 UUID 的相同文件哈希仍会保留为不同媒体记录。既有文件不会被覆盖，文件名冲突会获得确定性 UUID 后缀。音频和照片预览会在导入后重新生成；预览生成问题会以警告报告，不会丢弃已成功导入的媒体。导出接口为 `POST /api/v1/collection-bundle-exports`，导入会话使用 `POST /api/v1/data-imports`。

## 跟踪后台任务

使用 **Queue** 跟踪上传、分析、导出、导入等后台工作。打开记录可查看状态和结果数量。警告表示任务完成但有非阻断发现；错误表示至少一项必要操作失败。需要协助时，请向管理者提供 Queue 记录详情。
